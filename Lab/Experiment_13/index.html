🧪 Experiment 13

MongoDB & Mongoose Integration

Backend Development Laboratory

Home ← Laboratory

🎯 Objective

To understand database connectivity in a Node.js backend application using MongoDB and Mongoose.

📌 Project Overview

This experiment demonstrates the integration of MongoDB with a Node.js application using Mongoose. Mongoose provides a structured way to interact with MongoDB from JavaScript.

⚙️ Technologies Used

  • Node.js
  • JavaScript
  • MongoDB
  • Mongoose
  • npm

📂 Project Structure

│   └── node_modules/
│
└── index.html

🖥️ Backend Server

The main backend implementation is contained in server.js. The project dependencies and scripts are managed using npm and package.json.

🚀 Running the Project

Navigate to the Mongoose project directory:

cd mongoose-demo

Install dependencies:

npm install

Run the backend:

node server.js
Note: GitHub Pages supports static websites only. Node.js and MongoDB require a backend server and therefore cannot execute directly on GitHub Pages. This page presents the backend implementation included in the repository.

🎓 Learning Outcome

  • Understood MongoDB integration with Node.js.
  • Used Mongoose for MongoDB connectivity.
  • Worked with npm dependencies.
  • Understood the role of package.json.
  • Implemented server-side JavaScript using Node.js.
  • Understood backend database connectivity.

✅ Result

MongoDB and Mongoose backend integration was implemented successfully using Node.js.
