🎯 Objective

To understand the fundamentals of Git version control, configure Git identity, verify repository connectivity, track files, stage changes and create commits.

📚 What is Git?

Git is a Distributed Version Control System used to track changes in source code and maintain the history of a project. It allows developers to work collaboratively while managing different versions of their code.
