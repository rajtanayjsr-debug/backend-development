📌 Project Overview

Experiment 15 demonstrates backend web development using Django. A To-Do application is implemented using Django's project and application architecture with SQLite database integration.

⚙️ Technologies Used

  • Python
  • Django
  • SQLite Database
  • HTML
  • Django Templates

📂 Project Structure

Experiment 15/
├── todo/           Django Application
├── todo_project/   Django Project Configuration
├── db.sqlite3      SQLite Database
├── manage.py       Django Management Script
└── index.html      Experiment Presentation Page

🚀 Running the Django Project

The Django application runs using Django's development server.

python manage.py runserver
Note: GitHub Pages hosts static websites only. Django requires a Python server, so the backend application cannot execute directly on GitHub Pages. This page documents the Django implementation included in the repository.

🎯 Learning Outcome

This experiment demonstrates the structure of a Django project, creation of a Django application, database integration using SQLite, and development of a server-side web application.
