Django Backend Application

This experiment demonstrates the development of a To-Do application using Django, Python and SQLite.

The source files below show the Django models, views, URL configuration, templates and project configuration.

Note: The interface can be previewed on GitHub Pages. Dynamic Django operations such as adding, deleting and storing tasks require the Django server to be running.
