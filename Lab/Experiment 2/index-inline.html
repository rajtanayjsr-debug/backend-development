⚡ Inline CSS

Styles applied directly to individual HTML elements

What is Inline CSS?

Inline CSS uses the style attribute directly on HTML elements. This applies styles to specific elements only.

💡 Key Characteristic: Inline CSS has the highest specificity and will override all other styles.

Features of Inline CSS

🎯

Precise

Applies to a single element

⚡

Highest Priority

Overrides all other styles

🧪

Quick Testing

Fast for experimental styling

CSS Types Comparison

Feature Inline Internal External
Reusability ❌ No ⚠️ Limited ✅ Yes
Maintainability ❌ Hard ⚠️ Moderate ✅ Easy
Specificity Highest Medium Lowest
Caching ❌ No ❌ No ✅ Yes
Best For Single elements Single pages Multiple pages

Code Example

<h1 style="color: #e74c3c; font-size: 2.5rem; text-align: center;">
    Hello World
</h1>

<p style="background: #f8f9fa; padding: 15px; border-left: 4px solid #3498db;">
    This paragraph has inline styling for background, padding, and border.
</p>

<div style="display: flex; gap: 10px; justify-content: center;">
    <button style="background: #27ae60; color: white; padding: 10px 20px; border: none; border-radius: 5px;">Submit</button>
</div>
