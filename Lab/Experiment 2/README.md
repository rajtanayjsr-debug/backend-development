# Experiment 2: Cascading Style Sheets (CSS)

## Aim
To create web pages demonstrating different types of Cascading Style Sheets (CSS) and various CSS techniques.

## Course Outcome
CO2 – Create and build web pages and applications.

## Objectives
- Understand Inline, Internal, and External CSS.
- Apply different CSS selectors.
- Understand CSS specificity and inheritance.
- Implement responsive web design.
- Use Flexbox and CSS Grid for layouts.
- Implement CSS transitions and animations.

## Files Included

### 1. index-external.html
Demonstrates External CSS using a separate `styles.css` file.

### 2. styles.css
Contains the external stylesheet used by `index-external.html`.

### 3. index-internal.html
Demonstrates Internal CSS using the `<style>` tag inside the HTML document.

### 4. index-inline.html
Demonstrates Inline CSS using the `style` attribute directly on HTML elements.

### 5. index-selectors.html
Demonstrates different CSS selectors including:
- Element Selector
- Class Selector
- ID Selector
- Descendant Selector
- Child Selector
- Adjacent Sibling Selector
- General Sibling Selector
- Attribute Selector
- Pseudo-class Selector
- Pseudo-element Selector
- Combined Selectors

### 6. index-layout.html
Demonstrates modern CSS layout techniques:
- Flexbox
- CSS Grid
- Responsive Layout
- Grid Column and Row Spanning

### 7. index-animations.html
Demonstrates CSS transitions and animations including:
- Hover Transitions
- Bounce
- Pulse
- Spin
- Slide In
- Rainbow
- Float
- Typewriter Effect
- Animation Timing Functions

## Conclusion
In this experiment, different types of CSS were implemented successfully. External, Internal, and Inline CSS were demonstrated along with CSS selectors, Flexbox, Grid, responsive design, transitions, and keyframe animations.
