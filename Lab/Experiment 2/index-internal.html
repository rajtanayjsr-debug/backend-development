🎨 Internal CSS

Styling defined within the <style> tag in the head section

Understanding Internal CSS

Internal CSS is defined within the <style> element in the <head> section of an HTML document. It applies styles to that single page only.

When to Use Internal CSS

  • When styling a single page
  • When prototyping or testing styles
  • When page-specific overrides are needed
  • When external CSS is not feasible

Benefits of Internal CSS

📄

Single Page

Perfect for pages that need unique styling

🚀

Fast Load

No additional HTTP requests

🛠️

Easy Testing

Quick to modify and test

📦

Self-Contained

Everything in one file

Code Example

<style>
    body {
        font-family: Arial, sans-serif;
        background-color: #f0f4f8;
    }

    .page-header {
        background: linear-gradient(135deg, #2c3e50, #2ecc71);
        color: white;
        padding: 30px;
        text-align: center;
    }
</style>
