# Experiment 03: Create a Responsive Web Page with HTML and CSS

## Objective
To build a responsive web page from scratch using HTML5, CSS3, Flexbox, CSS Grid, and Media Queries without using any frameworks.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Tasks Performed

### Task 1 — HTML Skeleton with Viewport
Created the basic HTML structure with the viewport meta tag.

The viewport tag ensures that the web page adapts correctly to different device screen sizes.

### Task 2 — Flexbox Row (Desktop Layout)
Created three cards using CSS Flexbox.

On desktop screens, all three cards are displayed side by side in a horizontal row.
